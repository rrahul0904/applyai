# Mobile UX

## Status

Native iOS and Android are NOT STARTED and intentionally deferred.

## Planned platform

React Native, Expo, Expo Router, TypeScript, and EAS. Mobile will share API
contracts, business terminology, validation concepts, design tokens, analytics
names, and feature flags—not every web UI component.

## Candidate priorities

- recommendations and job discovery;
- save/skip and job detail;
- match explanation after matching is validated;
- application status cards and timeline;
- notifications and recruiter activity;
- interview preparation;
- profile and resume selection;
- resilient offline/error behavior.

Mobile tracking will use status sections and accessible quick actions rather
than shrinking a desktop Kanban board.
