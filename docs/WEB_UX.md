# Web UX

## CURRENT

- Public ApplyAI foundation page.
- Clerk sign-in/sign-up entry points when configured.
- Authenticated candidate workspace shell.
- Honest configuration and empty states.
- No hard-coded job cards, match scores, or fabricated analytics.
- Responsive layout, semantic landmarks, visible focus, adequate touch targets,
  and reduced-motion behavior.

## Candidate navigation

Planned primary navigation:

Dashboard, Jobs, Recommended, Saved, Applications, Resume, Interview Prep,
Career Insights, Profile, Settings.

Career Agent will remain contextual rather than consume primary navigation.

## First vertical-slice screens

1. Sign up/sign in.
2. Progressive onboarding.
3. Resume upload or skip.
4. Extracted profile review with provenance.
5. Database-backed job search with URL filters.
6. Job detail with source and freshness.
7. Saved jobs.
8. Application workspace with immutable timeline.

## Accessibility

Target WCAG AA: semantic HTML, logical headings, keyboard operation, focus
visibility, programmatic labels, error announcements, non-color status signals,
44px touch targets, and reduced motion.
